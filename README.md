# DAPI

Сайт команды DAPI. Делаем сайты; рядом — автоматизации, ИИ, исследования, ВПН.

Интерфейс построен по мотивам рабочей среды разработчика: слева дерево
разделов, в центре — единственная скроллящаяся зона, справа — лента работ.

## Как устроено

- `index.html` — весь макет и логика навигации
- `сетка.css` — система: модуль 35px, 42 колонки на 1470, стыковка линией 1px
- `фото/` — портреты команды

Пять разделов идут одним общим потоком — это «первая страница» (о нас,
команда, сайты — там же плиткой кейсы, автоматизации, контакты) — и на
контактах поток заканчивается. В ряду вкладок продублированы только
первые четыре (о нас, команда, сайты, автоматизации) — вкладки продают
сайты, контакты в них не дублируются, просто идут следом по скроллу.

Ии и llm, исследования, впн, процесс, мероприятия — разделы-окна:
открываются только из дерева слева, поверх основного потока, каждый
как отдельная страница.

Клавиша **G** показывает направляющие сетки.
